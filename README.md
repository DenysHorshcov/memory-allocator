# Memory Allocator

Власна реалізація `malloc`/`calloc`/`realloc`/`free` мовою C
(`os_malloc`, `os_calloc`, `os_realloc`, `os_free`) за завданням курсу
[Operating Systems — Memory Allocator](https://github.com/open-education-hub/operating-systems/tree/main/content/assignments/memory-allocator).

## Як це працює

- **Метадані**: `struct block_meta` (32 байти) перед кожним блоком; payload і
  метадані вирівняні до 8 байт.
- **Малі виділення** (`розмір + метадані < 128 КБ`, для `calloc` — `< розмір сторінки`)
  беруться з купи через `sbrk()`; більші — через `mmap()` і повертаються через `munmap()`.
- **Preallocation**: при першому використанні купи один раз виділяється 128 КБ.
- **Best fit**: перед пошуком суміжні вільні блоки зливаються (coalesce), потім
  обирається найменший підходящий вільний блок.
- **Split**: якщо залишок вміщує `block_meta` + хоча б 8 байт, блок ділиться.
- **Розширення купи**: якщо вільного блоку нема, розширюється останній блок
  (якщо він вільний), інакше додається новий.
- **`os_realloc`**: скорочує блок на місці; для розширення зливає наступні
  вільні блоки по одному, при потребі розширює останній блок через `sbrk()`,
  інакше переносить дані в новий блок. Для `STATUS_FREE` повертає `NULL`.
- Кожен системний виклик перевіряється через `DIE()`. `mremap()` не використовується.
